# 初步调查报告合同

按以下顺序输出：

1. **结论摘要**：只写本轮证据支持的总体判断，不作违纪定性。
2. **举报主线核查**：逐问题列出已确认事实、候选疑点、反证或正常解释、证据缺口。
3. **其他线索**：明确是否已与主被调查人和举报内容建立直接联系。
4. **数据质量与口径**：说明重复文件、重叠材料、字段问题、时间范围和计算限制。
5. **下一步**：按优先级列出补充调取、人工核对、继续直接解析或临时入库建议。

每个数字和关系紧邻写明相对文件路径、Sheet、真实字段、筛选条件、去重口径和可复核定位。需要原始值支撑证据时保留真实值，不生成`REDACTED`、`PHONE_REDACTED`或其他替代值；同时避免复制与结论无关的全量原始记录。
